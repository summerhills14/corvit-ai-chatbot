Azure Administrator Associate (Azure 104)
Curriculum
Course Overview
The Azure 104 course provides comprehensive training on Microsoft Azure, focusing on the core services, management tools, and security features. This course prepares students for the Azure Administrator certification (AZ-104) and equips them with the skills to manage Azure resources effectively.
Course Prerequisites
Basic understanding of cloud computing concepts
Experience with IT operations, including networking and virtualization
Familiarity with Azure services is beneficial
What We Learn in This Course
Introduction to Azure and its core services
Managing Azure subscriptions and resources
Implementing and managing storage
Configuring and managing virtual networks
Managing identities and governance
Securing and monitoring Azure resources
Hands-on labs and practical exercises
